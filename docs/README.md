# Документация Corelia

Актуализировано по локальным исходникам 16 сентября 2026 года. Описывает текущую реализацию, а не состояние установленного стенда.

## Начало работы

1. [Правила агента](../AGENTS.md): владельцы данных и границы изменений.
2. [Продукт](product.md): назначение, роли, виды документов, сценарии и ограничения.
3. [Реализация](implementation.md): компоненты, карта исходников и потоки данных.
