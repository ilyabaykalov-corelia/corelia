Проверены: JWT и ротация JWKS; login/refresh/logout; ограничения тел запросов; поиск/создание/изменение ПДС; процессы и инциденты; файлы и версии; очереди и действия задач; следующий шаг процесса; отсутствие клиентского сертификата и запрет вызовов от неподходящего сервиса.

Docker-сценарий прошёл через опубликованный gateway и четыре внутренних контейнера с mTLS. Авторизация, DataSpace, BPMX/BPMU и DAM в нём представлены локальной имитацией. Изменяющие операции рабочего стенда и нагрузочные испытания не выполнялись. Локальные параметры подключения скопированы из `sber-npf-java/.env` в игнорируемый `corelia/.env`; исходный файл не изменён.

Контейнеры, созданные для проверки, остановлены после выполнения. Образы и локальные сертификаты оставлены для повторного запуска через `scripts/up.sh`.

## Исправление совместимости GraphQL после проверки на рабочем стенде

Обнаружено, что прежняя имитация DataSpace допускала неизвестное имя `searchDocumentType` и изменённые тела операций. Это скрывало несовместимость со списком разрешённых запросов рабочего стенда. В адаптер Corelia добавлены точные зарегистрированные тексты, имя справочника исправлено на `refDocumentTypeListGet`.

Теперь имитация использует независимый снимок `src/test/resources/platform-v/allowed-requests.json`: проверяет имя и полный текст GraphQL-запроса до исполнения. Добавлены отрицательные проверки неизвестного имени и изменения тела зарегистрированного запроса. Это проверяет контракт запросов; выражения permissions и полную модель прав настоящей платформы имитация не исполняет.

Проверка использует локальную имитацию платформы и не изменяет данные рабочего стенда. Все шаблоны запросов сверяются с `sber-npf-platform-v/model.graphql-permissions.json`.

## Упрощение конфигурации развёртывания — 9 сентября 2026 года

Удалены внешний файл описания заказчика, его загрузчик, параметры окружения, Docker-монтирования и зависимости сервисов от этого механизма. Контракт ПДС сохранён в адаптере Platform V. Роли теперь берутся исключительно из подписанного токена, без исключения для логина `tester`.

Проверяется командой `mvn -B -ntp clean verify` на Java 25:

- Все девять Maven-модулей собраны успешно.
- Интеграционные тесты проверяют единый современный API Corelia.
- Проверены запуск пяти приложений без внешнего описания документов, каталог ПДС, PATCH, отклонение неизвестного типа и отсутствие дополнительных ролей у `tester`.
- Все восемь GraphQL-ресурсов адаптера точно совпали с разрешёнными телами операций в `sber-npf-platform-v/model.graphql-permissions.json`.
- `docker compose config --quiet` завершился успешно; Docker smoke-тест в этом запуске отключён. Работающие контейнеры не пересобирались и не перезапускались.

Чтобы применить изменения к локальным контейнерам, выполните `./scripts/up.sh` из корня Corelia.
